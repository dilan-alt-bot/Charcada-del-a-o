# ByteForge – La Velada del Año

## Descripción del proyecto

Este proyecto consiste en el diseño y desarrollo de una página web para una edición ficticia de La Velada del Año, realizada por nuestra empresa TIC ByteForge como parte del proyecto intermodular del CFGM 2 SMXB.

La web permite consultar información sobre el evento, conocer los combates, visualizar los horarios, consultar las entradas disponibles y acceder a diferentes apartados informativos.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño, estilos y adaptación de la web.
- **JavaScript:** funcionalidades interactivas, cálculos y validaciones.
- **Visual Studio Code:** entorno de desarrollo.
- **GitHub:** almacenamiento y gestión del código del proyecto.

## Estructura del proyecto

- `index.html`: página principal.
- `entradas.html`: información sobre las entradas.
- `faq.html`: preguntas frecuentes.
- `css/`: archivos de estilos de la web.
- `js/`: archivos JavaScript.
- `img/`: imágenes, logotipos y recursos gráficos.
- `info web/`: páginas de información y actividades.
- `Legal y Compromiso/`: aviso legal, política de privacidad y términos de venta.
- `Tienda Online/`: páginas relacionadas con la compra de entradas.

## Funcionalidades principales

- Página principal con información del evento.
- Cartel con los diferentes combates.
- Horarios de las actividades y actuaciones.
- Información sobre las entradas y sus precios.
- Formularios de compra con validaciones.
- Cálculo automático del precio de las entradas.
- Apartado de preguntas frecuentes.
- Secciones informativas y legales.
- Navegación entre las diferentes páginas de la web.

## Instalación y uso

1. Descargar o clonar el repositorio de GitHub.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. Navegar por las diferentes secciones de la página.

No es necesario instalar dependencias adicionales para visualizar la versión web, siempre que los archivos y recursos estén correctamente descargados.
